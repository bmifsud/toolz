# Toolz

Toolz is a utility repository containing automation scripts, backup & recovery workflows, Android personal automator bridges, and test suites.

## Project Structure

- **`android-personal-automator/`**: Android application setup and Python-based Termux bridge (`bridge/server.py`, diagnostic scripts).
- **`backup/`**: Comprehensive backup and snapshot management scripts (`backup_cline_omniroute.sh`, Debian container snapshotting, scheduled backup cron installers, and test suites).
- **`tests/`**: Core test runner and validation scripts (`run-all-tests.sh`, test automation scripts).

## Getting Started

Refer to individual module directories for execution scripts and testing instructions.
